# Pesquisa-de-opiniao

Este repositório contém um programa simples em Python para coletar respostas de 50 entrevistados.  
Cada entrevistado informa **nome**, **idade** e uma classificação da entrevista:

- `1` → Excelente  
- `2` → Boa  
- `3` → Ruim  

O programa contabiliza os totais e mostra a lista completa dos entrevistados.
